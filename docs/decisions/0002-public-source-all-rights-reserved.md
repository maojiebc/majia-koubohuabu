# ADR 0002：源码公开，保留所有权利

- 状态：已接受
- 日期：2026-10-09
- 补充：ADR 0001 第 1 条「独立私有仓库」的可见性改为公开，其余决策不变。

## 背景

口播画布已作为 `majia.pro/koubo` 公开上线，与公开的 `majia-chatcut-koubo` 构成上下游。仓库主人决定公开源码，但不开放复用授权。

## 决策

1. 仓库可见性改为公开。
2. 不附开源许可证；README 声明保留所有权利，未经书面授权不得复制、修改、再分发或商用，`vendor/portrait-talk-theme-kit/` 同样适用。
3. 部署脚本与文档中的 ECS 实例 ID、OSS 桶名、服务器 IP 保留原样：均非凭据，IP 可由域名公网解析得到，桶拒绝匿名访问，发布产物使用私有 ACL 与短时签名 URL。
4. 安全问题走 GitHub 私密漏洞报告。

## 公开前核查（2026-10-09）

范围为全部 6 个提交、109 个历史 blob，不只看当前版本：

- 历史中出现过的 82 个路径均仍在当前版本，没有被删除后残留在历史里的文件。
- 未发现 API key、token、私钥、JWT、赋值型密钥、手机号、身份证号或本机用户路径。
- 未出现雇主或客户名称，未出现飞书或内部系统链接。
- 20 个二进制文件为配色底图、示例海报、框架图和 vendor ZIP，逐张查看内容均为占位人像与通用文案。
- 提交邮箱已出现在其他公开仓库的提交中，不构成新的暴露。

## 后果

- 他人可以阅读源码与文档，但没有法律上的复用授权；以后改为开源许可证只需新增 LICENSE，反向收回已发布版本的授权则不可行。
- 之后的提交默认公开，`AGENTS.md` 中「不提交密钥」的约束需要继续严格执行。
