# 产品规格：口播画布

## 产品判断

口播视频的基本视觉模型不是「一张海报」，而是：

```text
录屏画面 1（证据） + 主讲人画面 2（表达） + 字幕（阅读） + 包装（系统性）
```

产品要解决的不是「生成更多漂亮图」，而是把每次剪辑中重复出现的画幅、坐标、裁切、字幕安全区、图层和交接决策沉淀为可复用规格。

## 目标用户

- 制作软件教程、AI 工具教程、数据复盘和知识讲解的自媒体创作者。
- 需要把电脑录屏与相机人像合成的剪辑师。
- 需要向 ChatCut、Codex 或其他 AI 剪辑代理交接画面规格的用户。

## 核心任务

1. 导入录屏和主讲人两路素材。
2. 选择横版 16:9 或竖版 9:16。
3. 在当前画幅中选择双画面构图。
4. 选择包装配色；三段文案与裁切选项自带默认值，需要时再展开「微调」。
5. 预览静态布局或本地视频。
6. 导出人与 AI 都能执行的交接包。

## 发布画幅

### 横版 16:9

- 画布：1920×1080。
- 字幕：底部单行，从 38–40px 起试。
- 画中画基线：300–360px 正方形可见框，优先右下且抬高到字幕上方。
- 原生版式：右下 PiP、左下 PiP、左屏右人、人物加强。

### 竖版 9:16

- 画布：1080×1920。
- 字幕：底部单行，从 84px 手机基线起试，建议每张约 13 个汉字以内。
- 录屏：不把完整横屏缩小后补黑边；按全貌、普通聚焦、密集 UI / 定向裁切分级。
- 人物：可在录屏下方居中，经典基线为约 480px 正圆。
- 原生版式：上屏下人、录屏放大 PiP、上下分屏、人物强表达。

## 配色系统

第一版使用 `portrait-talk-theme-kit` 的 8 套原始主题。它们从「整张海报底图」升级为双画面的语义包装色：

- `canvas`：全屏留白 / 底色。
- `surface`：录屏框、浏览器 chrome。
- `textPrimary` / `textSecondary`：标题与辅助文字。
- `accent` / `emphasis`：线条、人物边框与观点。
- `speakerSurface` / `speakerFigure`：人物槽位和占位。
- 字幕固定使用足够不透明的深色底与白字，并在真实录屏上验收。

## 导出契约

- PNG：当前视频帧 / 图片的静态成品预览。
- SVG：不嵌入本地素材的布局线框与安全区。
- JSON：scene spec、两个素材槽位、语义 token、字幕、音频和隐私规则。
- ChatCut JSX：固定画布、可编辑 properties、秒级时间基准与稳定静态回退。
- Markdown：给剪辑师或 AI Agent 的素材账本、坐标、图层和验收清单。
- ZIP：把上述 PNG / SVG / JSON / JSX / Markdown 一键打包成单个交接包。

## 非目标

- 不在浏览器内完成完整 NLE 剪辑。
- 不自动上传或云端保存用户素材。
- 不用抽象动效取代真实操作、数据或产品结果。
- 不宣称网页预览等于 ChatCut 实际导出。

## 验收标准

- 新用户可在 3 分钟内导入两路素材、选择画幅和版式、完成预览并导出 JSON / JSX。
- 不展开「微调」、不修改任何文字，也能直接预览并导出完整交接包。
- 所有布局在当前画布内，字幕不与人物碰撞。
- 圆形人像是正圆，脸部比例自然。
- 原始配色包的锁定文件未发生意外改变。
- 导出文档能清楚告诉下游：用什么素材、放在哪里、怎样裁切、怎样验收。
